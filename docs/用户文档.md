## 1. 系统简介

MetaMemory 是一个面向 AI Agent 的长期记忆系统，为您的 AI 应用提供：

| 能力 | 描述 |
|------|------|
| 📝 **记忆持久化** | 存储带分类标签和元数据的记忆条目，支持多租户隔离 |
| 🔍 **语义检索** | 基于深度学习 Embedding 的向量相似度搜索，R@5 = 0.465 |
| 📊 **可视化监控** | 仪表盘、分类分布图、属性雷达图、最近记忆列表 |
| ⚙️ **运行时配置** | 切换 Embedding 引擎、调整检索参数，无需重启 |
| 🖼️ **多模态支持** | 语音转文字、图像处理、内容分析（可选） |
| 🧪 **A/B 测试** | 内置分流实验框架，科学评估检索效果 |

**评估成绩**：综合评分 5.00/5 ★★★★★（EVALUATION_REPORT_v10.md）

## 2. 快速开始（5 分钟上手）

### 2.1 环境要求

| 组件 | 最低版本 | 说明 |
|------|---------|------|
| Python | 3.11+ | 推荐 3.12 |
| pip | 23.0+ | 包管理器 |
| 磁盘空间 | 2 GB | 含 .venv 虚拟环境 |
| 内存 | 4 GB+ | ST 模型需要约 500MB |

### 2.2 安装

```bash
# 1. 克隆项目（或解压交付包）
cd /path/to/MetaMemory

# 2. 创建虚拟环境（可选，推荐）
python3 -m venv .venv
source .venv/bin/activate  # Linux/macOS
# .venv\Scripts\activate   # Windows

# 3. 安装依赖
pip install -r requirements.txt

# 4. 配置 API Key
cp .env.example .env
# 编辑 .env，至少填入:
#   SILICONFLOW_API_KEY=sk-xxxxxxxxxxxx

# 5. 启动后端
python main_api.py
# 输出: Uvicorn running on http://0.0.0.0:8000

# 6. 打开前端
open frontend/index.html
# 或者用浏览器直接打开该文件
```

### 2.3 验证安装

```bash
# 健康检查
curl http://localhost:8000/health
# {"status":"ok","service":"yijing-agent-multi-tenant"}

# 系统统计
curl http://localhost:8000/api/v1/stats
# {"code":200,"data":{"memory_db":{...},"vector_db":{...}}}

# API 文档（自动生成）
open http://localhost:8000/docs
```

### 2.4 第一个记忆

```bash
# 创建记忆
curl -X POST http://localhost:8000/api/v1/memories \
  -H "Content-Type: application/json" \
  -d '{
    "agent_id": "test_agent",
    "memory_id": "mem_001",
    "content": "用户偏好 Python 编程，喜欢简洁的代码风格",
    "bagua_type": "乾",
    "wuxing": "金",
    "hot_score": 0.8
  }'

# 检索记忆
curl "http://localhost:8000/api/v1/memories/search?content=用户喜欢什么编程语言&top_k=5"
```

## 3. 生产部署指南

### 3.1 Nginx 反向代理

```nginx
# /etc/nginx/sites-available/metamemory

server {
    listen 80;
    server_name metamemory.your-domain.com;

    # 静态前端
    root /opt/metamemory/frontend;
    index index.html;

    # API 反向代理
    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # 超时设置（Embedding API 可能较慢）
        proxy_read_timeout 30s;
        proxy_connect_timeout 10s;
    }

    # 健康检查
    location /health {
        proxy_pass http://127.0.0.1:8000;
    }

    # Gzip 压缩
    gzip on;
    gzip_types application/json text/plain text/css;
}
```

### 3.2 systemd 服务

```ini
# /etc/systemd/system/metamemory.service

[Unit]
Description=MetaMemory AI Agent 长期记忆系统
After=network.target

[Service]
Type=simple
User=metamemory
Group=metamemory
WorkingDirectory=/opt/metamemory
Environment=PATH=/opt/metamemory/.venv/bin:/usr/local/bin:/usr/bin
EnvironmentFile=/opt/metamemory/.env
ExecStart=/opt/metamemory/.venv/bin/python main_api.py
Restart=on-failure
RestartSec=5

# 安全加固
NoNewPrivileges=yes
PrivateTmp=yes
ProtectSystem=strict
ProtectHome=yes
ReadWritePaths=/opt/metamemory/data

[Install]
WantedBy=multi-user.target
```

```bash
# 启动服务
sudo systemctl daemon-reload
sudo systemctl enable metamemory
sudo systemctl start metamemory
sudo systemctl status metamemory

# 查看日志
sudo journalctl -u metamemory -f
```

### 3.3 Supervisor 部署（备选）


### 3.4 Docker 部署

```dockerfile

FROM python:3.12-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .

```

```yaml

  metamemory:
    build: .
```

```bash

# 查看日志

```

## 4. 前端操作指南

MetaMemory 前端为单页面应用（SPA），共 5 个功能页面。直接双击 `frontend/index.html` 即可打开，无需 Web 服务器。

### 4.1 仪表盘

![仪表盘]

- **统计卡片**：总记忆数、Agent 数、平均热度
- **分类分布饼图**：按分类标签（原八卦）统计记忆分布
- **属性分布雷达图**：按属性标签（原五行）统计
- **最近记忆列表**：最新 10 条记忆摘要

### 4.2 记忆列表

- 分页表格，每页 20 条
- 支持按分类/属性/层级筛选
- 完整 CRUD 操作：
  - **新建**：填写内容 → 自动分类标签 → 保存
  - **编辑**：修改内容或标签
  - **删除**：二次确认后删除
- 搜索框：关键词过滤（前端本地搜索）

### 4.3 向量检索

- 输入框输入查询文本
- 选择 Top-K 数量（5/10/20）
- 点击搜索，返回语义匹配结果
- 每结果显示相似度分数和内容摘要

### 4.4 Agent 管理

- 查看所有已注册 Agent
- 注册新 Agent（填写 ID + 名称）

### 4.5 模型配置

- **Embedding 引擎**：SiliconFlow / 本地 ST / OpenAI / Hash
- **检索参数**：Top-K 数量、最低相似度阈值
- **LLM 编码端点**：占位配置
- 修改后点击"保存配置"，提示重启生效

## 5. 配置参数详解

### 5.1 完整配置参考

```yaml
# config.yaml — 含所有可配置项及说明

version: "2.2.0"              # 系统版本

server:
  host: "0.0.0.0"             # 监听地址
  port: 8000                  # 监听端口
  debug: false                # 调试模式（生产须为 false）

# ─── 数据库 ───
database:
  type: "sqlite"              # sqlite | mysql

  sqlite:
    path: "data/memory_system.db"  # SQLite 文件路径

  mysql:                      # MySQL 配置（仅 type=mysql 时生效）
    host: "localhost"
    port: 3306
    user: "root"
    password: "${MYSQL_PASSWORD}"  # 通过 .env 注入
    database: "memory_system"
    pool_size: 10             # 连接池大小
    max_overflow: 20          # 最大溢出连接

# ─── Embedding ───
embedding:
  provider: "siliconflow"     # siliconflow | sentence_transformer | openai | hash
  model: "BAAI/bge-large-zh-v1.5"
  dim: 1024                   # 向量维度
  cache_size: 5000            # 缓存条目数
  cache_ttl: 3600             # 缓存过期时间（秒）

  siliconflow:                # 硅基流动（免费 BGE）
    api_key: "${SILICONFLOW_API_KEY}"
    base_url: "https://api.siliconflow.cn/v1"
    model: "BAAI/bge-large-zh-v1.5"
    dim: 1024

  sentence_transformer:       # 本地离线模型
    model: "sentence-transformers/all-MiniLM-L6-v2"
    dim: 384
    offline: true

  openai:                     # OpenAI（付费）
    api_key: "${OPENAI_API_KEY}"
    base_url: "https://api.openai.com/v1"
    model: "text-embedding-3-small"
    dim: 1536

# ─── 检索 ───
retrieval:
  strategy: "pure_embedding"  # pure_embedding | hybrid
  top_k: 10                   # 返回数量
  min_similarity: 0.3         # 最低相似度 (0-1)

hybrid_retrieval:
  structural_weight: 0.0      # 结构权重（v2.3 归零，纯语义）
  semantic_weight: 1.0        # 语义权重

# ─── 分类标签编码 ───
yijing:
  encode_mode: "rule"         # rule (规则) | llm (大模型) | local (本地)

# ─── 日志 ───
logging:
  level: "INFO"               # DEBUG | INFO | WARNING | ERROR
  format: '%(asctime)s - %(name)s - %(levelname)s - %(message)s'

# ─── 跨域 ───
cors:
  allowed_origins:            # 允许跨域访问的域名
    - "http://localhost:3000"
    - "https://your-domain.com"
    - "null"                  # file:// 协议
```

### 5.2 环境变量 (.env)

```bash
# 必填（至少一个）
SILICONFLOW_API_KEY=sk-xxxxxxxxxxxx    # 硅基流动 API Key

# 可选
OPENAI_API_KEY=sk-xxxxxxxxxxxx         # OpenAI API Key
MYSQL_PASSWORD=your_password           # MySQL 密码

# 服务配置（可选，覆盖 config.yaml）
SERVER_HOST=0.0.0.0
SERVER_PORT=8000
LOG_LEVEL=INFO
```

## 6. 常见问题排查

### 6.1 启动失败

**症状**：`python main_api.py` 报错退出

| 错误 | 原因 | 解决 |
|------|------|------|
| `ModuleNotFoundError: No module named 'fastapi'` | 未安装依赖 | `pip install -r requirements.txt` |
| `端口 8000 已被占用` | 端口冲突 | `lsof -i :8000` 找到占用进程，或改 `config.yaml` 中 `server.port` |
| `No such file: config.yaml` | 配置文件缺失 | 确保在项目根目录执行 |
| `SILICONFLOW_API_KEY not set` | 缺少 API Key | 编辑 `.env` 填入 Key |

### 6.2 检索无结果

| 原因 | 检查方法 | 解决 |
|------|---------|------|
| 数据库为空 | `curl /api/v1/stats` 查看 memory_total | 先创建记忆 |
| 相似度阈值太高 | `config.yaml` 中 `min_similarity` > 实际分数 | 降低到 0.1-0.2 |
| Embedding 引擎失效 | 查看日志是否有 `Embedding API 调用失败` | 检查 API Key，或切换到 `hash`/`sentence_transformer` |
| 查询语言不匹配 | 中文查询 + 英文记忆 | 确保记忆语言与 Embedding 模型匹配 |

### 6.3 嵌入生成很慢

| 引擎 | 预期延迟 | 如果超过 |
|------|:------:|---------|
| SiliconFlow | ~200ms | 检查网络，或切换到本地 ST (82ms) |
| ST MiniLM | ~80ms | 首次加载需下载模型（~100MB），后续缓存 |
| Hash | <1ms | 无语义，仅兜底 |

**优化建议**：
1. 启用 Embedding 缓存（`cache_size: 5000`）
2. 对于高频查询，使用 `encode_batch()` 批量处理
3. 考虑部署本地 Embedding 服务降低延迟

### 6.4 数据库锁定

**症状**：`database is locked`

**原因**：SQLite 并发写入冲突

**解决**：
```bash
# 方案 1：切换到 WAL 模式
sqlite3 data/memory_system.db "PRAGMA journal_mode=WAL;"

# 方案 2：升级到 MySQL（生产推荐）
# 修改 config.yaml: database.type = "mysql"
```

### 6.5 前端无法连接 API

**症状**：仪表盘显示"加载失败"或空白

**检查清单**：
1. [ ] 后端是否运行：`curl http://localhost:8000/health`
2. [ ] CORS 是否允许前端域名：检查 `config.yaml` 中 `cors.allowed_origins`
3. [ ] 前端 JS 中 `API_BASE` 是否正确（默认 `http://localhost:8000`）
4. [ ] 浏览器控制台是否有 CORS 错误
5. [ ] 防火墙是否放行 8000 端口

## 7. 性能调优

### 7.1 数据库优化

```bash
# SQLite 优化
sqlite3 data/memory_system.db <<SQL
PRAGMA journal_mode=WAL;        -- 提升并发写入
PRAGMA synchronous=NORMAL;      -- 平衡安全与性能
PRAGMA cache_size=-64000;       -- 64MB 缓存
PRAGMA temp_store=MEMORY;       -- 临时表放内存
SQL
```

### 7.2 Embedding 优化

| 场景 | 推荐引擎 | 延迟 | 精度 |
|------|---------|:---:|:---:|
| 追求精度 | SiliconFlow BGE | 201ms | ⭐⭐⭐⭐⭐ |
| 低延迟要求 | ST MiniLM (本地) | 82ms | ⭐⭐⭐ |
| 离线环境 | ST MiniLM (本地) | 82ms | ⭐⭐⭐ |
| 极致速度 | Hash (仅调试) | <1ms | ⭐ |

### 7.3 检索优化

```yaml
# 减少返回数量，降低计算开销
retrieval:
  top_k: 5          # 从 10 降到 5
  min_similarity: 0.5  # 提高阈值，过滤低质结果
```

### 7.4 内存优化

| 组件 | 内存占用 | 优化方法 |
|------|:------:|---------|
| ST MiniLM 模型 | ~500MB | 切换到 SiliconFlow API（无本地内存占用） |
| FAISS 索引 | ~200MB (1M 向量) | 定期清理过期向量 |
| Embedding 缓存 | ~50MB (5000 条) | 减小 `cache_size` |
| Python 进程 | ~300MB | 使用 `gunicorn` 多进程可分摊 |

## 8. 版本迁移指南

### 8.1 v1.x → v2.3 主要变更

| 变更项 | v1.x (旧) | v2.3 (新) | 影响 |
|--------|----------|----------|------|
| 数据库 | MySQL + Redis + Milvus | SQLite (默认) + FAISS | 降低部署复杂度 |
| Embedding | 本地 ST 384d | SiliconFlow BGE 1024d (默认) | 检索精度 +69% |
| 检索策略 | 混合（六爻 + 语义） | 纯语义 (100%) | 六爻退化为分类标签 |
| 前端 | React SPA (需构建) | 纯 HTML (零构建) | 直接打开 |
| 模块数 | 48 (含虚构) | 43 (实际) | 清理死代码 |

### 8.2 数据迁移

```bash
# 如果从旧版 MySQL 迁移数据到新版 SQLite

# 1. 导出旧数据
mysqldump -u root -p memory_system yijing_memory > old_data.sql

# 2. 通过 API 批量导入新版
# 使用 Python 脚本逐条 POST /api/v1/memories
python scripts/migrate_v1_to_v2.py
```

### 8.3 配置迁移

```bash
# 旧 config.yaml 关键字段映射
embedding.provider: "sentence_transformer"  → "siliconflow"
database.type: "mysql"                      → "sqlite"
retrieval.strategy: "hybrid"                → "pure_embedding"
hybrid_retrieval.structural_weight: 0.3     → 0.0
```
