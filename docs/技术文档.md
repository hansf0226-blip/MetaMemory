### 2.2 与 FAISS 向量索引的对应关系

```
SQLite yijing_memory                     FAISS Index
┌──────────────────┐                    ┌─────────────────────┐
│ memory_id: abc   │──── 1:1 ────────► │ id: 1234             │
│ content: "..."   │                    │ vector: [0.12, ...]  │
│ agent_id: agt_1  │                    │ metadata: {          │
│ bagua_type: 乾   │                    │   memory_id: "abc",  │
│ wuxing: 金       │                    │   agent_id: "agt_1"  │
└──────────────────┘                    │ }                    │
                                        └─────────────────────┘

检索流程:
  1. FAISS 向量相似度搜索 → 返回 id + distance
  2. 通过 metadata.memory_id 回表查 SQLite
  3. 合并结果返回
```

### 3.2 抽象基类

```python
class EmbeddingProvider(ABC):
    """嵌入提供者抽象基类"""

    @abstractmethod
    def encode(self, text: str) -> List[float]:
        """编码单条文本为嵌入向量"""

    @abstractmethod
    def encode_batch(self, texts: List[str]) -> List[List[float]]:
        """批量编码"""

    @property
    @abstractmethod
    def dim(self) -> int:
        """嵌入维度"""

    @property
    @abstractmethod
    def name(self) -> str:
        """提供者名称"""
```

## 4. 检索策略与排序算法

### 4.1 v2.3 策略：纯语义检索

```python
# core/hybrid_retrieval.py

STRUCTURAL_WEIGHT = 0.0   # 六爻/分类不参与评分
SEMANTIC_WEIGHT   = 1.0   # 100% 语义向量

def compute_score(memory, query_vector):
    semantic = cosine_similarity(memory.vector, query_vector)  # [0, 1]
    return semantic  # 纯语义，结构权重为 0
```

**设计决策**（Phase 3B, 2026-04-28）：
- 六爻 rule 编码区分度为 **-0.2**（完全反向），不是正向信号
- 六爻退化为**纯分类标签**，用于前端 UI 过滤，不影响检索排序
- 检索评分 100% 依赖 Embedding 语义相似度

### 4.2 排序管道

```
候选集 (FAISS 召回 top_k × 3)
    │
    ▼
Agent 过滤 (agent_id 强制匹配)
    │
    ▼
语义评分 (cosine_similarity × 1.0)
    │
    ▼
热度加权 (hot_score 正相关)
    │
    ▼
去重 (memory_id 唯一)
    │
    ▼
Top-K 截断
    │
    ▼
返回结果 + 内容截断 (前 100 字符)
```

### 4.3 相似度阈值

| 参数 | 默认值 | 说明 |
|------|:-----:|------|
| `min_similarity` | 0.3 | 低于此分数不返回 |
| `top_k` | 10 | 最多返回条数 |
| 内容截断 | 100 字符 | 超过则加 "..." |

```yaml
# config.yaml
retrieval:
  strategy: "pure_embedding"
  top_k: 10
  min_similarity: 0.3
```

### 6.2 全局异常处理器

```python
# main_api.py — FastAPI exception handlers

@app.exception_handler(NotFoundError)
def handle_not_found_error(request, exc):
    logger.error(f"资源不存在: {exc.message}")
    return JSONResponse(
        status_code=404,
        content={"code": exc.code, "message": exc.message, "details": exc.details}
    )

# ... 类似处理其余 8 种异常

@app.exception_handler(Exception)
def handle_generic_error(request, exc):
    """兜底处理：所有未捕获异常 → 500"""
    logger.error(f"未知错误: {str(exc)}")

        status_code=500,
        content={"code": 500, "message": "内部服务器错误", "details": {"error": str(exc)}}
    )
```

## 8. API 设计原则

| 原则 | 实现 |
|------|------|
| **统一前缀** | 所有 API 以 `/api/v1/` 开头 |
| **RESTful** | 资源名词复数，HTTP 方法决定操作 |
| **统一响应** | `{"code": 200, "data": ...}` 或 `{"code": 4xx, "message": "..."}` |
| **主动脱敏** | `GET /config` 自动将 api_key / password 替换为 `***` |
| **全链路追踪** | 响应头 `X-Request-ID` + `X-Process-Time-Ms` |
| **OpenAPI 文档** | FastAPI 自动生成 `/docs` (Swagger) + `/redoc` |
