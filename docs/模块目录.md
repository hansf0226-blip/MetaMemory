## 4. 存储适配层

### 4.1 数据模型 (SQLAlchemy ORM)

```python
# core/models.py — YijingMemory 表 (368 行)

class YijingMemory(Base):
    __tablename__ = "yijing_memory"

    id              = Column(Integer, PK, autoincrement)
    agent_id        = Column(String(64), index=True)     # 多租户键
    memory_id       = Column(String(64), unique=True)    # 唯一标识
    hexagram        = Column(String(6))                  # 六爻编码
    bagua_type      = Column(String(10), index=True)     # 分类标签
    wuxing          = Column(String(10), index=True)     # 属性标签
    sancai_layer    = Column(String(10), index=True)     # 层级标签
    content         = Column(Text, nullable=False)       # 正文
    hot_score       = Column(Float, default=0.5)         # 热度
    weight          = Column(Float, default=0.5)         # 权重
    redundancy      = Column(Float, default=0.0)         # 冗余度
    access_count    = Column(Integer, default=0)         # 访问计数
    yao_history     = Column(JSON, default=[])           # 变更历史
    created_at      = Column(DateTime, server_default=func.now())
    updated_at      = Column(DateTime, onupdate=func.now())
    expire_time     = Column(DateTime)
```

## 7. 模块间调用关系

```
                        main_api.py
                       (路由 + 中间件)
                            │
         ┌──────────────────┼──────────────────┐
         │                  │                  │
         ▼                  ▼                  ▼
   schemas.py        storage_manager      multimodal.py
   (数据校验)         (统一入口)            (多模态)
                         │
         ┌───────────────┼───────────────────┐
         │               │                   │
         ▼               ▼                   ▼
   embedding_        memory_db/         hybrid_
   provider.py       mysql_store.py     retrieval.py
   (向量化)          (关系存储)          (检索排序)
         │               │                   │
         ▼               ▼                   ▼
   缓存 (LRU)        SQLite/MySQL        FAISS Index

图例:
  ──► 同步调用
  ─ ─► 依赖注入 (工厂模式)
  ····► 定时任务 (APScheduler)
```

**通信模式**：
1. **直接调用**：API → StorageManager → 子模块，同步方法调用
2. **工厂模式**：`get_storage_manager()`, `create_embedding_provider()` 提供单例
3. **发布-订阅**：APScheduler 定时任务（自愈、衰减、清理）
4. **HTTP**：Embedding 引擎通过 REST API 调用 SiliconFlow/OpenAI
